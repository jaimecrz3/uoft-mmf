# University of Toronto — Master of Mathematical Finance (MMF)

This repository contains selected coursework, notes, assignments, and projects completed during the **Master of Mathematical Finance (MMF)** at the **University of Toronto**.

The repository serves as a central hub for my work throughout the program. Larger projects may be maintained in separate repositories and linked from the corresponding course folder.

## Repository Structure

```text

│
├── fall-term/
│   ├── course-name/

│   └── ...
│

│

    ├── course-name/
```

Each course directory may contain a combination of:

- Python or R notebooks
- Code and numerical implementations
- Data analysis
- Assignments
- Personal notes and summaries
- Links to larger project repositories

## Projects

Some projects completed during the program are maintained in separate GitHub repositories. These are linked from the relevant course directories rather than duplicated here.

Projects completed collaboratively are explicitly identified as **team projects**, together with my individual contributions where appropriate.

## About the MMF

The Master of Mathematical Finance at the University of Toronto combines mathematical finance, data science, machine learning, risk management, financial markets, and computational methods.

Program information is available on the [University of Toronto MMF website](https://www.mmf.utoronto.ca/).
