# Projects

This course includes three applied projects designed to demonstrate the
practical use of numerical methods in finance.

Each project is maintained in a separate GitHub repository so that the
code, analysis, results, and documentation can be presented independently.

## Project 1 — Pairs Trading

A Monte Carlo study of a Coca-Cola–Pepsi pairs trade.

The project explores:

- Simulation of correlated stock-price paths
- Monte Carlo methods
- Correlation and mean-reversion assumptions
- P&L distributions
- Expected trade value
- Tail outcomes
- Entry and exit rules

[View repository →](https://github.com/jaimecrz3/pairs-trading-monte-carlo)

## Project 2 — Credit Risk

A Monte Carlo study of credit risk in a portfolio of BBB-rated corporate bonds.

The project compares a multivariate Gaussian model with a Gaussian copula to understand how credit rating changes, defaults, and dependence between issuers affect portfolio losses.

The project explores:

- Credit rating transitions and default probabilities
- Simulation of 1,000,000 future portfolio values
- Multivariate Gaussian and Gaussian copula models
- Expected credit losses and 99% Credit VaR
- Dependence between bond issuers
- Portfolio diversification with 2, 10, and 100 bonds
- The impact of extreme credit events on portfolio risk

[View repository →](https://github.com/jaimecrz3/credit-risk-monte-carlo-copulas)
