# Machine Learning — MMF2030H

**Master of Mathematical Finance — University of Toronto**  
**Fall 2026**

## Course Overview

This course develops machine learning from a unified risk-minimization framework, combining statistical foundations with practical applications in quantitative finance and financial decision-making.

The course covers the full machine learning workflow, from problem formulation and feature engineering to model estimation, evaluation, interpretability, and integration into financial applications.

### Topics

- Risk minimization and statistical learning
- Linear regression and K-nearest neighbours
- Feature engineering
- Maximum-likelihood and Bayesian estimation
- Statistical learning theory
- Tree-based models and gradient boosting
- Model interpretability with SHAP and LIME
- Neural networks and backpropagation
- Clustering and principal component analysis
- Hierarchical Risk Parity (HRP)
- Custom loss functions
- Reinforcement learning
- Large language models
- Machine learning applications in quantitative finance

### Assignment 2 — Gradient Boosting, Neural Networks and Hierarchical Risk Parity

The second assignment focuses on the practical implementation and evaluation of machine learning models for credit-risk classification and portfolio construction.

Topics covered:
- Decision-tree entropy and information gain
- Backpropagation and gradient computation
- XGBoost classification and hyperparameter selection
- Feature importance and SHAP explanations
- Feedforward neural network architectures
- Regularization and overfitting
- Model comparison using out-of-sample performance
- Hierarchical Risk Parity (HRP)
- Portfolio allocation and diversification
- Comparison with Markowitz mean-variance optimization
